# 16 · 机器方块、模型与近距提示

## 获取与标记

创造物品栏的「回声托运站」分页收录全部 12 类机器，ID 均使用 `noellesroles:` 命名空间。
放置时正面朝玩家，支持四个水平朝向、结构旋转与镜像。机器为单格静态多部件模型，
不含方块实体、不触发原版容器 GUI，不新增按键或依赖；完整碰撞与原来的地图路线校验保持一致。

**放下机器不会自动创建玩法目标。** 仍需用回声地图编辑仪或 `/sre:echo map mark ...`
把其所在方块标记为对应点位并保存。不要把这些机器放进会被开关还原的核心门/撤离门体积。

| 方块 ID | 编辑器点位类型 | 外观辨识 |
|---|---|---|
| `echo_beacon` | `beacon_open` | 青蓝透镜、黄铜框与天线 |
| `echo_core_beacon` | `beacon_core` | 金色共鸣外壳 |
| `echo_crystal_extractor` | `crystal` | 晶体夹爪、采集仓 |
| `echo_key_altar` | `altar` | 阶梯台座、声纹钥匙槽 |
| `echo_supply_crate` | `supply` | 包角、提手与锁扣货箱 |
| `echo_black_market` | `black_market` | 紫色封印保险箱 |
| `echo_black_crystal_extractor` | `black_node` | 紫晶采集仓 |
| `echo_black_dropoff` | `black_dropoff` | 黑晶接收斗与投入口 |
| `echo_core_console` | `core_control` | 钥匙孔与门控显示屏 |
| `echo_free_exit` | `free_control` | 绿色安全出口指示 |
| `echo_evacuation_console` | `evacuation_control` | 橙金警示撤离终端 |
| `echo_broker_exit` | `broker_exit` | 黄铜凭证/票据终端 |

新生成的庄园自动放置对应机器，核心/撤离面板朝可通行的一侧。
不会自动迁移或覆盖旧地图；旧地图已标记的普通方块仍能交互并获得同样的近距提示。
旧点位外壳可以手动替换为同类机器，但保留坐标与已保存配置。

## 世界浮字与 HUD

- 对局中面向 4.5 格内、无遮挡的机器，正面上缘出现一行「机器名称 · 操作/状态」。
  优先显示准星目标；走远、转身、隔墙、旁观、打开菜单或隐藏 HUD 时不显示。
- 左侧信息流增加带方块图标的紧凑机器卡片。信标同时显示投料数量、充能百分比和进度条。
  低分辨率信息区拥挤时只保留世界浮字，不覆盖底部物资栏或已有引导条。
- 空手右键提示跟随玩家的实际使用键；过载跟随现有职业技能键。投机客退场提示导向背包中的
  私人契约确认，不错误提示右键退场。撤离终端提示进入真正的撤离检测区，不把终端本身当撤离区。
- 可用、缺资源、满货、钥匙占用、恢复、封锁、充能、已启动、阶段限制、阵营/契约限制、暂停、
  倒地和受控等状态由服务器投影。只发送本人当前可见的一台机器，不广播私人契约或整张地图。
- 本地倒计时最多外推一个同步周期，不自动宣布成功/刷新。服务器每 10 tick 同步；超过 25 tick
  未更新、离开维度或切换对局会清理旧提示。查看机器不会启动动作或修改拒绝原因。
- 非对局时瞄准机器也会显示名称，但明确标注为地图机器外壳。

三语文案独立放在 `assets/echo_machines/lang/{zh_cn,zh_tw,en_us}.json`，避免与其他 HUD 文案冲突。
模型与贴图生成源在 `tools/echo-freight/generate_{logistics,terminal}_models.py`，
资源已提交为普通 JSON/PNG；**不要运行 datagen**。

## 验收

离线回归：`EchoMachineMappingTest` 检查 12 种映射、33 个点位和可通行朝向；
`EchoMachineViewTest` 检查状态边界、暂停计时、三语键与模型/朝向/物品/掉落/不透明贴图引用。

游戏内待验：分别以托运者、截流者、投机客和旁观者靠近机器，核对空手/持物、采集恢复、
投料充能/污染、钥匙开门、开箱、黑晶专属投放、退场确认、撤离与过载；
再测试改键、隔墙、转身、F1、暂停、切维度、断线重连与 320×240 GUI。
离线资源测试和编译不能替代上述实际游戏验收。
